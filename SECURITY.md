# Security Policy

## Supported scope

This repository is maintained as a public portfolio / engineering project. Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do **not** open a public issue containing credentials, exploit details, personal data, or other sensitive material.

For a potentially sensitive security report, contact the maintainer through the contact methods linked from the GitHub profile or portfolio and include:

- the affected component or file;
- steps to reproduce;
- the potential impact;
- any suggested remediation, if known.

For non-sensitive hardening suggestions, a normal GitHub issue is appropriate.

## Secrets

No real API keys, tokens, passwords, or private credentials should be committed to this repository. Use environment variables or GitHub Actions secrets for credentials.
