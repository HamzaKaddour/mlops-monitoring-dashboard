Lifecycle implemented in this repository

  1. Train: three candidate classifiers on deterministic synthetic churn data.
  2. Track: MLflow records parameters and validation metrics in local SQLite.
  3. Select: choose the best candidate by validation ROC-AUC.
  4. Serve: FastAPI loads the selected joblib artifact for POST /predict.
  5. Observe: SQLite stores prediction events and monitoring artifacts track drift and quality.
  6. Review: a policy combines performance degradation and PSI drift into a retraining recommendation.
